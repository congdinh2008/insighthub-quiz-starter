# Bộ tài liệu giả lập

Chỉ upload các file nghiệp vụ `.md` bên cạnh README này. Nội dung là dữ liệu giả lập do chương trình biên soạn, không đại diện cho chính sách của bất kỳ tổ chức nào.

Dùng cùng bộ dữ liệu cho demo, test và đánh giá hồi quy. Fixture mode chỉ kiểm tra luồng phần mềm, không đo chất lượng truy hồi ngữ nghĩa. PDF có thể tạo từ chính các nội dung này để kiểm tra parser; PDF scan/OCR ngoài phạm vi.
